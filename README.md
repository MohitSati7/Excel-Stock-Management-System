Excel Stock Management System

About the Project

The Excel Stock Management System is a spreadsheet-based project developed using Microsoft Excel-compatible formulas and formatting in WPS Office. It helps track inventory transactions and monitor available stock.

Features

Stock In: Records incoming items, quantities, prices, and amounts.

Stock Out: Records outgoing items, quantities, prices, and amounts.

Stock Available: Displays item quantities and inventory amounts.

Automatic calculations using spreadsheet formulas.

Color-coded sections for better readability.

Indian Rupee (₹) currency formatting.

Tools Used

WPS Office Spreadsheets

Microsoft Excel-compatible spreadsheet formulas

GitHub for project hosting and version control

How to Use

Download Stock_Management_System.xlsx from this repository.

Open the workbook in WPS Office or Microsoft Excel.

Enter stock-in and stock-out transactions.

Review the stock availability and amounts.

Verify formulas and inventory balances before using the data.
